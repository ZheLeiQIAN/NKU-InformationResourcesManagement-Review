## 二、高频简答题库（33 题）

### 第1章

**【简答1】简述归纳与演绎的区别，并各举一例。**

| 维度 | 归纳 | 演绎 |
|------|------|------|
| 思维方向 | 特殊→一般 | 一般→特殊 |
| 起点 | 观察和数据 | 理论和假设 |
| 过程 | 观察 → 模式 → 理论 | 理论 → 假设 → 观察 → 验证 |
| 典型方法 | 扎根理论、案例研究、访谈 | 问卷调查、实验、SEM |

- **归纳例**：李月琳等（2021）通过日记法+访谈，归纳出跨源健康信息搜寻的行为路径模型。
- **演绎例**：王晰巍等（2023）基于 S-O-R 框架、D&M 模型和社会反应理论提出假设，通过问卷验证。

**【简答2】简述研究伦理的四大原则。**

1. **自愿参与**：参与者必须出于自愿，不能强迫。
2. **无害原则**：研究不能对参与者造成任何伤害。
3. **匿名与保密**：保护参与者隐私，数据使用必须脱敏。
4. **分析与报告**：诚实、客观地报告研究结果，不篡改数据。

**【简答3】简述基础研究与应用研究的区别。**

| 维度 | 基础研究 | 应用研究 |
|------|---------|---------|
| 目的 | 探索人类生活本质；追求理论建构 | 解决具体实践问题 |
| 关注点 | 知识本身的扩展和理论完善 | 与社会实践、政策、行业问题直接相关 |
| 资金 | 学术基金（国家社科基金） | 行业、企业、政府委托 |
| 例子 | 李月琳"健康信息搜寻行为"理论研究 | 数字图书馆交互评估工具开发 |

**关系**：基础研究为应用研究提供理论基础，应用研究为基础研究提供问题来源；不是对立而是相互促进。

### 第2章

**【简答4】简述三种定义的含义与区别。**

| 定义类型 | 含义 | 特点 | 示例 |
|---------|------|------|------|
| **真实定义** | 用本质属性界定概念 | 追求"是什么"，反映客观实在 | "人是理性的动物" |
| **名义定义** | 研究者赋予的约定性意义 | 追求"指什么"，是研究者的约定 | 本研究将"信息素养"界定为…… |
| **操作定义** | 明确规定如何测量 | 追求"怎么测"，连接理论与现实 | 满意度=李克特5级量表总分 |

**关系**：从抽象到具体的递进——真实定义→名义定义→操作定义→真实世界测量。

**【简答5】简述概念化与操作化的过程。**

- **概念化**：将模糊的抽象概念清晰化、具体化的过程，明确概念的内涵和外延。
- **操作化**：将概念进一步转化为可测量的具体指标和测量方法的过程。
- **操作链条**：概念 → 维度 → 指标
  - 例：信息素养 → 信息检索/评价/使用/伦理能力 → "我能够使用布尔运算符构建复杂检索式"（5级量表）
- **指标互换性**：同一概念的不同指标之间可以相互替代进行测量；指标间相关性低可能说明概念界定不清。

**【简答6】简述测量的四个要素。**

| 要素 | 含义 | 通俗理解 |
|------|------|---------|
| **测量客体** | 测量的对象 | 测"谁" |
| **测量内容** | 客体的属性或特征 | 测"什么" |
| **测量法则** | 为属性赋值的方案 | 怎么"测" |
| **数字或符号** | 测量结果的表示形式 | 测出来"是什么" |

例：测量大学生信息素养水平——客体=大学生；内容=信息素养；法则=李克特5级量表+测试题；结果=87分。

**【简答7】简述四种测量层次并各举两例。**

| 层次 | 核心特征 | 示例 |
|------|---------|------|
| **定类** | 仅分类，无顺序 | 性别、民族、职业 |
| **定序** | 可排序，差值无意义 | 教育程度、满意度排名 |
| **定距** | 可排序、间距相等，无绝对零点 | 温度、智商、公元纪年 |
| **定比** | 有绝对零点，可乘除 | 收入、体重、年龄 |

**判断口诀**：能否排序？间距是否相等？是否有绝对零点？

**【简答8】简述信度与效度的关系。**

- **关系**：信度是效度的**必要非充分条件**——效度高则信度一定高；信度高不一定效度高。
- **打靶类比**：信度=箭是否集中，效度=箭是否射中靶心。
- **四种组合**：
  - 高信度 + 高效度 = 理想状态 ✓
  - 高信度 + 低效度 = 系统偏差 ✗（箭集中但偏离靶心）
  - 低信度 + 高效度 = 理论上不可能
  - 低信度 + 低效度 = 完全失败 ✗

### 第3章

**【简答9】简述概率抽样与非概率抽样的主要区别。**

| 维度 | 概率抽样 | 非概率抽样 |
|------|---------|-----------|
| 随机性 | 每个要素被抽中的概率**已知且相等**（EPSEM） | 概率**未知** |
| 代表性 | 可确保样本代表性 | 不能确保 |
| 推断总体 | 可进行统计推断 | 不能进行统计推断 |
| 方法 | 简单随机、系统、分层 | 方便、判断、滚雪球、配额 |
| 适用 | 大样本、定量研究 | 小样本、质性研究、探索性研究 |

**【简答10】简述四种非概率抽样方法及其适用场景。**

| 方法 | 通俗理解 | 适用场景 |
|------|---------|---------|
| **方便抽样** | "逮着谁算谁" | 图书馆门口拉人填问卷；同学朋友帮忙 |
| **判断抽样** | "专家挑人" | 预调查（pilot study）；理论抽样 |
| **滚雪球抽样** | "熟人介绍熟人" | 研究聋哑人、HIV感染者等难寻找群体 |
| **配额抽样** | "按比例凑数" | 需保证性别/年龄比例与总体一致 |

**【简答11】简述三种概率抽样方法的步骤。**

1. **简单随机抽样（SRS）**：给总体每个要素编号→用随机数表或计算机随机数选取→被选中的组成样本。最基础但不常用（难获取完整名单）。
2. **系统抽样**：从完整名单中**每第 K 个要素**组成样本（K=N/n）；**起点要随机确定**；操作更简单因而更受欢迎。风险：若名单按某种规律排序会引入偏差。
3. **分层抽样**：把总体按某种特征分成若干层（如按年级分）→从**每一层内**分别抽取适当数量。优点：可提高代表性，确保各层都有样本。

**【简答12】简述案例研究的适用条件（Yin 三个条件）。**

1. 研究问题的类型是"怎么样"和"为什么"
2. 研究对象是目前**正在发生**的事件
3. 研究者对当前事件**不能控制**或仅能进行极低程度的控制

三个条件**同时满足**时，案例研究是最贴切的方法选择。

**【简答13】简述单案例与多案例、整体性与嵌入性案例研究的区别。**

| 维度 | 类型 | 说明 |
|------|------|------|
| **案例数量** | 单案例 | 批判性/独特性/典型性/启示性/历时性 |
| | 多案例 | 增强效度和信度；逐项复制、差别复制 |
| **分析单元** | 整体性 | 仅考查案例的整体特征 |
| | 嵌入性 | 一个研究中同时存在多个分析单元 |

**【简答14】简述对案例研究的常见误解。**

- 案例研究是定性的，而定性研究又是非理性、不科学的 → **错误**
- 案例研究是一种初级的研究方法 → **错误**
- 案例研究中所选择的案例越多越好 → **错误**
- 案例研究是一种容易的方法 → **错误**
- 案例研究样本太小，不足以说明任何问题 → **错误**

正确理解：案例研究是**严谨的实证研究方法**，可质可量。

### 第4章

**【简答15】简述质性研究的特点和不足。**

**特点**：
1. 自然环境下开展
2. 着重从数据内容、内涵挖掘
3. 研究者亲自体验或参与
4. 研究者本人即为研究工具
5. 不预设理论与假设
6. 归纳式研究
7. 深入探究和理解

**不足**：
1. 与研究者的主观认知密切相关
2. 研究结果的推广性不足
3. 研究过程往往缺乏对变量的严格控制
4. 耗时耗力

**【简答16】简述 Kvale（1996）提出的深度访谈七个阶段。**

1. **主题化（Thematizing）**：明确研究主题和目的
2. **设计（Designing）**：设计研究方案和方法
3. **访谈（Interviewing）**：实施访谈，建立信任关系
4. **转录（Transcribing）**：将录音资料转为文本
5. **分析（Analyzing）**：对文本数据进行编码和分析
6. **验证（Verifying）**：验证研究结果的可靠性
7. **报告（Reporting）**：撰写研究报告

**【简答17】简述焦点小组访谈的优缺点。**

**优点**：
- 深入挖掘问题（群体互动激发思维）
- 聚焦主题（主持人引导控制）
- 真实数据（受访者自然表达）
- 丰富数据（多角度观点）

**缺点**：
- 依赖受访者记忆
- 数据分析复杂（多人发言交织）
- 推广性问题（样本代表性）
- 群体压力风险（个体会附和多数意见）

**关键设计要素**：每组 **8-12 人**；至少 **2 组**（一组结论不可靠）；话题聚焦 1-2 个核心问题。

### 第5章

**【简答18】简述问卷的三个组成部分及其作用。**

1. **封面信**：致被调查者的短信，说明研究者身份、调查内容、目的、调查对象选取方法、保密措施及致谢。**作用：争取配合**。
2. **指导语**：指导被调查者填答问卷的各种解释和说明。**作用：确保数据质量**。
3. **问题与答案**：问卷主体部分，包括开放式和封闭式问题。**作用：收集数据**。

**【简答19】简述答案设计的穷尽性和互斥性原则。**

- **穷尽性**：答案**包括了所有可能的情况**——每个受访者都能找到适合自己的选项。
  - 反例：年龄分组"20-30、30-40、40-50"→缺了 20 岁以下和 50 岁以上。
- **互斥性**：答案之间**不能相互交叉重叠**——每个受访者只能选一个。
  - 反例：职业选项"教师、教授、讲师"→三者交叉。

**【简答20】简述问题语言的七条规范。**

1. 语言要尽量简单
2. 问题的陈述要尽可能简短
3. 问题要避免带有双重或多重含义
4. 问题不能带有倾向性
5. **不用否定形式**提问
6. 不问回答者不知道的事情
7. **不要直接问敏感性问题**

**【简答21】简述问题排序的基本原则。**

1. 简单易答的问题放在前面
2. 能够引起兴趣的问题放在前面
3. 将被调查者熟悉的问题放在前面
4. **先问行为方面的问题，再问态度、意见、看法方面的问题**
5. 个人背景资料一般放在结尾
6. 若有开放式问题应放在最后

**【简答22】简述问卷设计的四大原则和五大步骤。**

**四大原则**：
| 原则 | 说明 |
|------|------|
| 简明性 | 问题简单明了，避免复杂句式和专业术语 |
| 适应性 | 问题符合受访者的认知水平和回答能力 |
| 目的性 | 每个问题都服务于研究目的 |
| 针对性 | 针对研究对象特点设计（儿童、老人需特别考虑） |

**五大步骤**：
1. 探索性摸底（文献+访谈+观察）
2. 设计初稿
3. 试用（预调查 30-50 人）
4. 修改定稿
5. 排版印刷

### 第6章

**【简答23】简述华莱士科学环的内容与意义。**

- **科学环四节点**：理论 → 假设 → 观察 → 经验概括
- **两个方向**：
  - 演绎（顺时针）：理论 → 假设 → 观察 → 经验概括（**检验理论**）
  - 归纳（逆时针）：观察 → 经验概括 → 理论（**建构理论**）
- **意义**：演绎和归纳**互补**，不存在"只演绎不归纳"或"只归纳不演绎"的研究——任何一项研究都至少走半个环。
- **三种画法**：完整闭环（成熟研究）/半环顺时针（纯理论验证）/半环逆时针（纯探索建构）。

**【简答24】简述三级编码的过程及其关系。**

- **开放编码（Open Coding）**：对数据进行初始分类和概念标记；产出大量初始代码；**贴近数据**，用受访者原话作代码。
- **主轴编码（Axial Coding）**：将开放编码产生的范畴与次范畴关联；回答 4W1H（when/where/why/who/how）；产出范畴与子范畴的关系。
- **选择编码（Selective Coding）**：识别研究中的中心编码；整合主轴编码形成更一般的概念；产出**核心理论或模型**（故事线）。

**关系**：从具体到抽象、从分散到整合的递进过程；典型归纳法应用。

**【简答25】简述挖矿与旅行两种隐喻的视角对比。**

| 隐喻 | 视角 | 类比 | 启示 |
|------|------|------|------|
| **挖矿** | 客观主义 | 数据中已"埋藏"着意义，研究者"挖掘"出真相 | 强调发现的客观性，研究者尽量保持中立 |
| **旅行** | 建构主义 | 知识是研究者与情境互动的产物，不同人"看到"的不同 | 承认研究者的主观参与和视角差异 |

- 量化研究倾向于"挖矿"
- 质性研究倾向于"旅行"
- 两种视角在质性研究中并存，现代质性研究更多采用建构主义立场

**【简答26】简述备忘录的三种类型及其作用（Strauss & Corbin, 1998）。**

1. **Code notes（编码笔记）**：识别编码标签及其含义，记录每个代码的定义和边界。
2. **Theoretical notes（理论笔记）**：对概念维度、深层含义、概念间关系的反思，推动理论建构。
3. **Operational notes（操作笔记）**：记录方法论问题，如抽样决策、数据收集过程中的问题。

**作用**：备忘录是质性研究中研究者与数据对话的重要工具，有助于保持分析的透明性和系统性。

### 第7章

**【简答27】简述 p 值的含义及判断标准。**

- **p 值（p-value）**：样本观察到结果在总体中偶然出现的概率。
- **判断标准**：
  - p < 0.05 → 拒绝零假设（H₀），结果统计显著
  - p ≥ 0.05 → 不能拒绝零假设，没有足够证据认为存在差异/关系
- **逻辑**：设零假设 H₀（总体中没有差异）→ 计算 p 值 → p 很小说明 H₀ 不太可能成立。
- **重要提醒**：p < 0.05 是最常用的显著性水平，但 **p 值本身不表示效应大小**。

**【简答28】简述 PLS-SEM 测量模型评估的三个维度及其标准。**

**1. 内部一致性信度**
- 组合信度 CR：0.70-0.90 为可接受；< 0.60 不足；> 0.95 提示冗余

**2. 收敛效度**
- 外载荷（Outer Loading）：> 0.708（解释 50% 以上方差）
- 平均方差提取量 AVE：> 0.50

**3. 区分效度**
- Fornell-Larcker 准则：AVE 平方根 > 与其他构念的相关系数
- HTMT 比率：< 0.85（严格）或 < 0.90（宽松）

**【简答29】简述中介效应与调节效应的区别。**

| 效应 | 回答的问题 | 表达方式 | 示例 |
|------|----------|---------|------|
| **中介效应（M）** | "为什么 X 影响 Y？" | X → M → Y | 品牌社群参与 → 品牌认同感 → 忠诚度 |
| **调节效应（W）** | "X 的作用对谁更强？" | X × W → Y | 产品涉入度调节"参与→认同"路径 |

- **中介**揭示作用机制；**调节**揭示边界条件。

### 第8章

**【简答30】简述文献回顾的五个目的。**

1. **促进理论发展**（facilitates theory development）
2. **关闭已有研究过多的领域**（closes areas where a plethora of research exist）
3. **发现需要研究的领域**（uncovers areas where research is needed）
4. **加强研究领域的主要方向**（strength some major as one field of study）
5. **为后续研究提供指导**（enable the senior to advise）

**【简答31】简述 Webster 和 Watson（2002）提出的文献回顾七个步骤。**

1. **开始**：定义关键变量，设定边界（分析层次、情境限制、范围、分析单元），阐明贡献
2. **识别相关文献**：不局限于单一领域，从顶级期刊开始，Go backward 和 Go forward
3. **结构化回顾**：以概念为中心组织，使用表格，通过分类增加价值
4. **语气**：避免过度批判，尊重前人工作
5. **理论发展**：构建概念模型，提出研究命题
6. **评估理论**：检验是否可解释、可预测、简洁、可证伪、有用
7. **讨论与结论**：展示如何扩展过去研究，建议实证检验方法，提炼实践启示

**【简答32】简述"以概念为中心"与"以作者为中心"的区别。**

| 维度 | 以概念为中心（推荐） | 以作者为中心 |
|------|------------------|------------|
| 组织方式 | 围绕研究主题和核心概念 | 按作者或时间顺序罗列 |
| 优点 | 逻辑清晰；揭示概念间关系；识别空白 | 简单易写 |
| 缺点 | 需要分析综合能力 | 变成"电话簿"（Bem, 1995） |

**实践方法**：使用表格组织文献（变量、方法、发现、空白）；按主题分组讨论；比较和对比不同研究的发现；指出研究间的矛盾与共识。

**【简答33】简述"Go backward"和"Go forward"两种文献检索策略。**

- **Go backward（回溯）**：回顾已识别关键文章的参考文献，追溯研究的理论根源和早期基础。
- **Go forward（前推）**：使用 Web of Science 等工具，识别引用关键文章的后续研究，追踪研究的最新发展。

**意义**：两种策略结合使用，可全面把握研究脉络，既了解理论基础，又掌握前沿动态。

## 三、综合论述题库（10 题）

### 【论述1】请结合具体研究案例，论述社会科学研究中的归纳与演绎两种研究路径

**答题框架**：

1. **概念辨析**（对比表 + 思维方向 + 过程 + 典型方法）
2. **两者关系**（互补、不可分割——华莱士科学环）
3. **典型研究举例**：
   - 演绎例：王晰巍等（2023）智慧图书馆聊天机器人研究——基于 S-O-R 框架、D&M 模型和社会反应理论提出假设→问卷收集数据→结构方程模型验证
   - 归纳例：李月琳等（2021）跨源健康信息搜寻研究——日记法+半结构化访谈→开放/主轴/选择编码→归纳出"健康信息搜寻行为路径模型"
4. **总结**：实际研究中归纳与演绎常交替使用，体现华莱士科学环的"环"思想。

### 【论述2】论述信度与效度的关系，并举例说明高信度低效度的情形

**答题框架**：

1. **概念辨析**
   - 信度：测量结果的一致性/稳定性（箭是否集中）
   - 效度：测量的准确性（箭是否射中靶心）
2. **关系**：信度是效度的**必要非充分条件**；四种组合状态（高/低信度 × 高/低效度）
3. **举例说明高信度低效度**：
   - 用体重秤测身高——每次测出来都接近（高信度），但测的不是身高（低效度）
   - 用李克特量表测"图书馆满意度"时，量表设计有系统偏差（题目都偏正面）——每次结果都稳定（高信度），但测的不是真实满意度（低效度）
4. **实践启示**：研究设计阶段应同时关注信度与效度；信度只是基础，效度才是终极目标。

### 【论述3】论述案例研究法的适用条件、设计类型及方法论问题

**答题框架**：

1. **定义**：深入研究现实生活环境中正在发生的现象（案例），特别适用于现象与所处环境背景的界限不明显的场景。
2. **适用条件（Yin 三个条件）**：研究"怎么样""为什么" + 正在发生 + 不可控
3. **设计类型**：
   - 单案例（批判/独特/典型/启示/历时性）vs 多案例（逐项复制/差别复制）
   - 整体性（单分析单元）vs 嵌入性（多个分析单元）
4. **方法论问题**：对案例研究的常见误解（不科学/初级/案例越多越好/容易方法）
5. **应用举例**：T 公司战略规划人员信息搜寻行为研究——单案例嵌入性设计，以项目为分析单元，通过参与式观察+日记+深度访谈收集数据，开放编码分析。

### 【论述4】论述概率抽样与非概率抽样的区别，并举例说明不同研究情境下的抽样方法选择

**答题框架**：

1. **核心区别**（EPSEM + 代表性 + 推断）
2. **概率抽样方法**：简单随机/系统/分层
3. **非概率抽样方法**：方便/判断/滚雪球/配额
4. **情境举例**：
   - 研究南开图书馆读者信息需求（有完整名单）→ **系统抽样**（每 K 个抽 1）
   - 研究聋哑人信息搜寻行为（难接触）→ **滚雪球抽样**
   - 预调查问卷设计 → **判断抽样**（30-50 名有代表性特征的人）
   - 城市居民满意度调查（需保证性别/年龄比例）→ **配额抽样**
5. **总结**：抽样方法的选择关键看三件事——是否有完整抽样框、研究对象是否容易接触、是否需要保证比例。

### 【论述5】论述质性研究的特点，并以李月琳团队的"跨源健康信息搜寻行为"研究为例说明研究设计

**答题框架**：

1. **质性研究七大特点**：自然环境、内涵挖掘、研究者参与、研究者本人为工具、不预设假设、归纳式、深入探究
2. **研究案例**：李月琳等（2021）跨源健康信息搜寻行为研究
   - **研究问题**：用户在多源（医生+家人+网络等）健康信息情境下的搜寻行为路径
   - **方法**：日记法（过程性数据）+ 半结构化访谈（深度数据）
   - **样本**：30 名左右有健康信息需求的成年人
   - **分析**：三级编码（开放→主轴→选择）→ 归纳出行为路径模型
   - **贡献**：补充了意义建构理论在跨源情境下的应用
3. **方法论启示**：
   - 多种数据收集方法结合（三角验证）
   - 强调过程性数据（弥补访谈的"回溯偏差"）
   - 适合探索性研究、建构新理论

### 【论述6】论述三级编码在质性数据分析中的作用与操作要点

**答题框架**：

1. **概念**：三级编码是扎根理论的核心方法，是从数据到理论的递进过程
2. **三阶段详解**：
   - 开放编码：贴近数据，用受访者原话作代码（**摘菜**）
   - 主轴编码：归类成范畴，回答 4W1H（**分组**）
   - 选择编码：提炼核心范畴，构建故事线（**主厨**）
3. **操作要点**：
   - 顺序固定不能颠倒
   - 开放编码要贴近数据，避免过早抽象
   - 主轴编码要回答 when/where/why/who/how
   - 选择编码要找"故事线"而非简单堆砌范畴
4. **应用举例**：新冠疫苗认知演变研究——26 人访谈 → 开放编码 100+ 概念 → 主轴编码 6 大障碍范畴 → 选择编码"四阶段认知演变"故事线
5. **考试应用**：三级编码是质性研究方法论的核心考点。

### 【论述7】论述问卷设计中"问题语言规范"和"答案设计原则"的重要性

**答题框架**：

1. **问题语言七规范**（简单/简短/无双重/无倾向/不否定/不敏感/不问不懂）
2. **答案设计两原则**（穷尽性 + 互斥性）
3. **反例与纠正**：
   - 否定形式提问："您是否不赞成公共场所吸烟？" → 改为"您是否赞成公共场所吸烟？"
   - 直接问敏感问题："您的收入是多少？" → 改为区间选项
   - 倾向性提问："大多数医生都认为……你同意吗？" → 改为中立提问
   - 答案不互斥：职业"教师、教授、讲师" → 重新设计为单一分类
4. **设计实践**：四大原则（简明/适应/目的/针对）+ 五大步骤（探索→初稿→试用→定稿→排版）
5. **总结**：问卷设计质量直接决定数据质量，是定量研究的"地基"。

### 【论述8】论述 PLS-SEM 在信息资源管理研究中的适用场景，并说明其与 CB-SEM 的选择依据

**答题框架**：

1. **PLS-SEM 适用场景**：
   - 探索性研究、提出新理论
   - 中小样本（n < 300）
   - 数据非正态分布
   - 新量表开发、预测导向
2. **CB-SEM 适用场景**：
   - 理论验证、成熟量表
   - 大样本（n > 300）+ 正态分布
   - 模型拟合度要求高
3. **选择依据表**：

| 维度 | CB-SEM | PLS-SEM |
|------|--------|---------|
| 统计哲学 | 基于协方差 | 基于方差最大化 |
| 样本要求 | 大样本+正态 | 中小样本，支持非正态 |
| 目标 | 模型拟合 | 预测能力 |
| 研究阶段 | 理论验证 | 理论探索 |

4. **应用举例**：王晰巍等智慧图书馆聊天机器人研究——理论成熟+成熟量表→适合 CB-SEM；某新兴健康信息行为研究——新概念+小样本→适合 PLS-SEM
5. **总结**：选择的核心是看"研究阶段（探索/验证）"和"样本与数据特征"。

### 【论述9】论述为什么文献回顾应该"以概念为中心"而非"以作者为中心"

**答题框架**：

1. **两种方式的对比表**（见简答32）
2. **以作者为中心的问题**（"电话簿"式罗列——Bem, 1995）：
   - 缺乏分析和综合
   - 难以揭示研究间内在联系
   - 读者无法获得领域整体结构
3. **以概念为中心的优势**：
   - 围绕主题组织，逻辑清晰
   - 揭示概念间关系
   - 识别研究空白和未来方向
   - 增加文献回顾的分析价值
4. **实践方法**：表格组织（变量/方法/发现/空白）+ 按主题分组 + 比较对比 + 指出矛盾与共识
5. **应用举例**：以"信息素养"为概念的文献回顾——按"信息检索能力/评价能力/使用能力/伦理"四个维度组织文献，而非按作者罗列。

### 【论述10】论述社会科学研究中定量与质性方法的选择依据，并以"健康信息行为"主题为例说明

**答题框架**：

1. **方法特点对比**（10 个维度：目的/层面/设计/手段/工具/抽样/资料/分析/结论/本质）
2. **选择依据**：
   - 研究目的：检验理论→定量；建构理论→质性
   - 研究问题："多少人/怎么样"→定量；"为什么/怎么样（深入）"→质性
   - 资料特征：可量化数据→定量；文本/话语→质性
3. **健康信息行为研究举例**：
   - **定量例**（演绎）：王晰巍等——基于 S-O-R 框架提出假设→问卷调查→结构方程模型验证健康信息搜寻行为的影响机制
   - **质性例**（归纳）：李月琳等——日记法+半结构化访谈→三级编码→归纳跨源健康信息搜寻行为路径
4. **混合研究趋势**：实际研究中常将两者结合，发挥各自优势。

## 四、高频易错点（考前必看）

| 易错点 | 错误记忆 | 正确记忆 |
|--------|---------|---------|
| 信度与效度关系 | 信度高 → 效度一定高 | 信度是效度的**必要非充分条件** |
| 定距 vs 定比 | 温度是定比测量 | 温度是**定距**（无绝对零点）；收入才是定比 |
| p 值含义 | p < 0.05 表示效应很大 | p 值表示**概率**，**不表示效应大小** |
| 案例研究本质 | 案例研究=定性=不科学 | 案例研究是**严谨的实证研究**，可质可量 |
| 焦点小组人数 | 4-5 人或 20 人 | **8-12 人**，至少 2 个组 |
| 相关 vs 因果 | 相关系数高说明有因果 | 相关只衡量**协同变化**，不证明因果 |
| ANOVA vs 多次 t | 三组比较用多次 t 检验 | 三组以上用 **ANOVA**，多次 t 增加 I 类错误 |
| 归纳 vs 演绎 | 归纳/演绎是替代关系 | **互补**（华莱士科学环）|
| 总体 vs 研究总体 | 两者相等 | 研究总体是**可接触的子集**，未必等于总体 |
| 文献回顾写法 | 按作者罗列研究 | **以概念为中心**组织，避免"电话簿"式罗列 |
| 编码顺序 | 三级编码可任意顺序 | **固定顺序**：开放 → 主轴 → 选择 |
| 测量层次方向 | 低层次可转高层次 | **只能**高层次转低层次 |
| 自变量/因变量 | 自变量是结果 | 自变量=**原因**；因变量=**结果** |
