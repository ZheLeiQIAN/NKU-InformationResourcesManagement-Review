## 每章结构（Harness 8模块）

1. 【模块定位】—— 学科位置与考试权重
2. 【知识图谱】—— 树状结构图
3. 【核心概念】—— ★必考 + ☆重要概念表
4. 【重点公式/算法】—— 关键公式与判断标准
5. 【方法比较】—— 对比辨析表
6. 【考试聚焦】—— 考点分级与题型预测
7. 【模拟练习】—— 名词解释/简答/论述，折叠答案
8. 【自测清单】—— 掌握度自检

## 使用方式

1. 按章节顺序复习，每章通读8模块
2. 考前用附录「考前速记卡」快速回顾（6大板块：必背概念/公式/方法/案例/统计选择/易错点）
3. 闭卷完成模拟练习，对照答案找薄弱点
