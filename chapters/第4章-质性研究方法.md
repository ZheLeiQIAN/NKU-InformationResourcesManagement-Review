# 第4章 质性研究方法

## 【模块定位】

本章是质性研究的"方法模块"，重点介绍深度访谈、焦点小组、日记法、观察法等核心质性数据收集方法。质性研究在信息资源管理领域广泛应用于信息行为、用户体验等研究主题。

## 【知识图谱】

```
质性研究方法
├── 为何采用质性研究？
│   ├── 无法定量描述
│   ├── 需要观察、交流
│   └── 处理非结构化数据
├── 深度访谈 ★
│   ├── 类型（结构化/半结构化/非结构化）
│   ├── 七个阶段（Kvale, 1996）
│   ├── 访谈大纲设计
│   └── 数据处理（开放编码）
├── 焦点小组访谈
├── 日记法
└── 观察法（参与式/非参与式）
```

## 【核心概念】

### 1. 质性研究的特点 ★必考

| 特点 | 说明 |
|------|------|
| 自然环境下开展 | 在真实情境中收集数据 |
| 着重内容、内涵挖掘 | 深入理解现象的意义 |
| 研究者亲自体验或参与 | 参与式观察 |
| 研究者本人即为研究工具 | 研究者的主观性是不可避免的 |
| 不预设理论与假设 | 归纳式研究 |
| 深入探究和理解 | 追求深度而非广度 |

**不足**：
- 与研究者的主观认知密切相关
- 研究结果的推广性不足
- 研究过程往往缺乏对变量的严格控制
- 耗时耗力

### 2. 深度访谈的类型 ★必考

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **结构化访谈** | 严格按照预设问题提问 | 大样本、标准化数据收集 |
| **半结构化访谈** | 有访谈大纲，但可灵活调整 | 质性研究中最常用 |
| **非结构化访谈** | 完全开放，无预设问题 | 探索性研究 |

### 3. 深度访谈的七个阶段（Kvale, 1996）★必考

1. **Thematizing（主题化）**：明确研究主题
2. **Designing（设计）**：设计研究方案
3. **Interviewing（访谈）**：实施访谈
4. **Transcribing（转录）**：将录音转为文本
5. **Analyzing（分析）**：数据分析
6. **Verifying（验证）**：验证结果
7. **Reporting（报告）**：撰写报告

### 4. 访谈大纲设计 ☆重要

**什么叫访谈大纲？**

访谈大纲是访谈开始前准备的"问题清单 + 流程脚本"，相当于访谈时的"地图"——既保证关键问题都问到，又给追问留出空间。

> **通俗类比**：访谈大纲就像记者的采访提纲。记者不会现场瞎聊，会提前想好"开场问什么、核心问什么、收尾问什么、遇到冷场怎么接"。访谈大纲就是研究者的"采访提纲"。

**访谈大纲的三个组成部分**：

| 部分 | 英文 | 作用 | 示例 |
|------|------|------|------|
| **简介部分** | Instruction to interview | 说明访谈目的、保密原则、录音授权，打消受访者顾虑 | "本次访谈大约30分钟，所有信息将匿名处理，您可以随时退出。请问您同意录音吗？" |
| **访谈问题** | Interview questions | 按主题/逻辑顺序排列的核心问题 | "请谈谈您最近一次为完成作业而查找资料的经历" |
| **问候语** | Greetings and ending words | 开场暖场语 + 结束感谢语 | 开场："感谢您抽出时间"；结束："非常感谢您的分享，如有问题可随时联系我" |

**设计依据（为什么要这样设计？）**：

访谈大纲不是凭空编出来的，要**回到研究本身**，对应三件事：

| 依据 | 含义 | 怎么用 |
|------|------|--------|
| **研究问题** | 你到底想回答什么问题 | 大纲中每个问题都应**服务于某个研究问题**；无关问题要砍掉 |
| **变量** | 你想研究的影响因素和结果 | 把变量转化为"可问"的问题（这就是"操作化"） |
| **概念化和操作化** | 抽象概念怎么变成具体问题 | 如"信息素养"太抽象→操作化为"您如何使用图书馆数据库？" |

**一个完整的半结构化访谈大纲示例（以"大学生信息搜寻行为"研究为例）**：

```
一、导入（5分钟）
   1. 请问您目前读几年级？所学专业是？
   2. 平时学习和生活中，您最常需要查找哪些类型的信息？
      【作用：暖场 + 了解背景】

二、信息搜寻过程（10分钟）
   3. 请您回忆最近一次为完成课程作业而查找资料的经历，详细描述您是怎么做的。
   4. 在这个过程中，您遇到过什么困难？是如何解决的？
      【作用：开放性问题，鼓励受访者详细叙述】

三、信息评价与选择（8分钟）
   5. 当您找到一批信息时，如何判断哪条更可信、更有用？
   6. 您更倾向于使用哪些信息源？为什么？
      【作用：追问态度和判断标准】

四、补充与结语（7分钟）
   7. 关于信息搜寻这件事，您还有什么想分享的？
   8. 感谢您的参与！如后续需要确认或补充，我会再联系您。
      【作用：开放式收尾 + 表达感谢】
```

**设计原则小结**：
1. **由易到难**：先问背景性、事实性问题，再问感受性、评价性问题
2. **由宽到窄**：先问开放式大问题，再逐步聚焦
3. **避免诱导**：不要问"您觉得搜索引擎很方便，对吗？"（诱导），而问"您使用搜索引擎的频率如何？"（中立）
4. **留追问空间**：准备"您能再具体说说吗？""当时您的感受是？"等追问话术

### 5. 焦点小组访谈 ☆重要

**什么叫焦点小组？**

把 6-12 个**有共同背景**的人聚在一起，由主持人围绕特定话题引导讨论，**通过群体互动激发观点**。

> **通俗类比**：焦点小组就像"圆桌讨论会"。相比一对一访谈，它能让人在听别人观点时被激发，想起更多东西。

**关键设计要素**：

| 要素 | 要求 | 为什么 |
|------|------|--------|
| **访谈对象** | 小组而非个体 | 通过互动激发观点 |
| **组数** | 至少 2 组 | 一组结论不可靠，至少要 2-3 组才能比较 |
| **每组人数** | 8-12 人（常见） | 太少讨论不起来，太多每人发言不足 |
| **话题聚焦** | 围绕 1-2 个核心问题 | 避免"漫无边际" |

**优点**：
- 深入挖掘问题（群体互动激发思维）
- 聚焦主题（主持人引导控制）
- 真实数据（受访者自然表达）
- 丰富数据（多角度观点）

**缺点**：
- 依赖受访者记忆
- 数据分析复杂（多人发言交织）
- 推广性问题（样本代表性问题）
- 群体压力风险（个体会附和多数意见）

### 6. 日记法 ☆重要

**什么叫日记法？**

请研究参与者**在真实生活情境中、按统一要求记录自己的经历、想法、感受**，研究者事后回收分析。

> **通俗类比**：日记法就像"作业日志"。研究者给参与者发一本"日志本"，规定"请你每天晚上睡前花10分钟记录今天的……"，一段时间后研究者收回来分析。

**日记法的三步操作**：

| 步骤 | 内容 |
|------|------|
| **第一步：设计日记大纲** | 规定"记什么、怎么记"——如"请记录你今天为完成作业查找资料的过程，包括：何时查、用什么工具、找到什么、有什么感受" |
| **第二步：给参与者指南（guide）** | 写一份清晰的"说明书"——交代目的、方法、字数要求、提交方式、保密承诺 |
| **第三步：回收与分析** | 持续一段时间（如2周）后回收日志，对内容进行编码和主题分析 |

**日记法的特点**：

| 特点 | 说明 |
|------|------|
| **生态效度高** | 在真实生活中记录，避免"回忆偏差" |
| **过程性数据** | 能捕捉"行为随时间的变化"——这是访谈做不到的 |
| **样本量小** | 5-30 人即可——因为每人提供多日数据 |
| **数据量大** | 每人每天 200-500 字，2 周 14 天 = 2800-7000 字/人 |
| **对参与者要求高** | 需要自律、愿意持续记录、写作能力基本达标 |

**典型适用场景**：
- 健康信息行为追踪（每日记录"今天查了什么健康信息、为什么"）
- 学习过程研究（每日记录"今天的学习行为、困难"）
- 消费决策研究（每日记录"今天买了什么、为什么、感受"）

**示例：跨源健康信息搜寻的日记研究**：

```
日记大纲（节选）
1. 今天你有过主动查找健康相关信息吗？（是/否）
2. 如果有，请描述：什么时间、什么场合？
3. 你通过哪些渠道查找？（搜索引擎 / 微信公众号 / 医生 / 家人朋友 / 其他）
4. 你对这些信息的信任程度如何？（1-5 分）
5. 你最后采用了什么信息作为依据？
```

> **考试理解要点**：日记法 = 在自然环境中获得**过程性**数据；与访谈互补（访谈=回溯，日记=实时）。

### 7. 观察法

| 类型 | 特点 |
|------|------|
| **参与式观察** | 研究者参与到被观察者的活动中 |
| **非参与式观察** | 研究者不介入被观察者的活动 |

## 【重点公式/算法】

本章无数学公式，重点在于研究设计和访谈技巧。

## 【方法比较】

| 维度 | 深度访谈 | 焦点小组 | 日记法 | 观察法 |
|------|---------|---------|--------|--------|
| 数据深度 | 深 | 中等 | 深 | 深 |
| 样本量 | 小（10-30） | 小（每组8-12） | 小 | 小 |
| 互动性 | 一对一 | 群体互动 | 无 | 视参与程度 |
| 适用 | 个人经历、态度 | 群体观点、共识 | 行为过程 | 行为模式 |

<details>
<summary>【模拟题1】简答题：简述质性研究的特点和不足</summary>

**答案**：

**特点**：
1. 自然环境下开展
2. 着重从数据内容、内涵挖掘
3. 研究者亲自体验或参与
4. 研究者本人即为研究工具
5. 不预设理论与假设
6. 归纳式研究
7. 深入探究和理解

**不足**：
1. 与研究者的主观认知密切相关
2. 研究结果的推广性不足
3. 研究过程往往缺乏对变量的严格控制
4. 耗时耗力

**解析**：质性研究的核心优势是"深度"，核心局限是"主观性"和"推广性"。
</details>

<details>
<summary>【模拟题2】名词解释：半结构化深度访谈</summary>

**答案**：半结构化深度访谈是一种质性数据收集方法，研究者事先准备访谈大纲，但在访谈过程中可根据受访者的回答灵活调整问题的顺序和内容，允许深入追问和探索意外发现。

**解析**：这是信息资源管理研究中最常用的访谈类型，兼具结构性和灵活性。
</details>

<details>
<summary>【模拟题3】简答题：简述Kvale（1996）提出的深度访谈七个阶段</summary>

**答案**：
1. **主题化（Thematizing）**：明确研究主题和目的
2. **设计（Designing）**：设计研究方案和方法
3. **访谈（Interviewing）**：实施访谈，建立信任关系
4. **转录（Transcribing）**：将录音资料转为文本
5. **分析（Analyzing）**：对文本数据进行编码和分析
6. **验证（Verifying）**：验证研究结果的可靠性
7. **报告（Reporting）**：撰写研究报告

**解析**：七个阶段构成完整的访谈研究流程，考试中可能要求按顺序写出。
</details>

<details>
<summary>【模拟题4】选择题：焦点小组访谈每组适宜的人数是？</summary>

A. 4-5人  
B. 8-12人  
C. 12-15人  
D. 20-30人

**答案**：B

**解析**：焦点小组每组8-12人是较为理想的规模，既能保证讨论的丰富性，又能确保每个人都有发言机会。人数过少（A）讨论不够充分；人数过多（C、D）难以管理。
</details>

<details>
<summary>【模拟题5】研究设计题：设计一个关于"大学生信息搜寻行为"的半结构化访谈大纲（至少包含5个问题）</summary>

**答案示例**：

**访谈大纲：大学生信息搜寻行为研究**

**一、导入问题**
1. 请问您平时在学习和生活中最常需要查找哪些类型的信息？
2. 您一般通过什么渠道获取这些信息？

**二、信息搜寻过程**
3. 当您需要查找某个主题的信息时，您通常会怎么做？请详细描述一下您的过程。
4. 在信息搜寻过程中，您遇到过哪些困难？是如何解决的？

**三、信息评价与选择**
5. 您如何判断找到的信息是否可靠和有用？
6. 您更倾向于使用哪些信息源？为什么？

**四、网络信息搜寻**
7. 您在网络上搜索信息时，通常使用什么策略？
8. 您如何评价当前网络信息的质量？

**五、结语**
9. 对于改善信息搜寻体验，您有什么建议？
10. 关于信息搜寻行为，您还有什么想补充的？

**解析**：访谈大纲应围绕研究问题设计，从一般到具体，从行为到态度，最后开放性问题。
