## 二、必背公式与判断标准（15个，按考试频率排序）

| 频率 | 名称 | 表达式 | 易错点 |
|:---:|------|--------|--------|
| ★★★ | Cronbach's α | $\alpha = \frac{k}{k-1}\left(1 - \frac{\sum \sigma_{Y_i}^2}{\sigma_X^2}\right)$ | 整体>0.80，各维度≥0.65 |
| ★★★ | 样本量公式 | $n = \frac{Z^2 \times p(1-p)}{e^2}$ | 95%置信+5%误差→n≈389 |
| ★★★ | p值判断 | $p < 0.05$ 拒绝零假设 | p值不表示效应大小 |
| ★★★ | 信度系数标准 | $r \geq 0.8$ 为高；$r \geq 0.65$ 为可接受 | r=1无误差，r=0无关 |
| ★★★ | KMO值 | $KMO = \frac{\sum r_{ij}^2}{\sum r_{ij}^2 + \sum u_{ij}^2}$ | >0.9适合；<0.5不适合 |
| ★★★ | Pearson相关系数 | $r = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2\sum(y_i-\bar{y})^2}}$ | 范围-1~+1，不表因果 |
| ★★ | Kappa系数 | $\kappa = \frac{P_o - P_e}{1 - P_e}$ | ≥0.8高度一致；<0.4较差 |
| ★★ | 卡方统计量 | $\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$ | 期望频数≥5（至少80%格子） |
| ★★ | 标准差 | $SD = \sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}}$ | 分母是n-1不是n |
| ★★ | AVE | $AVE = \frac{\sum \lambda_i^2}{n}$ | >0.50为可接受 |
| ★★ | CR（组合信度） | 0.70-0.90为可接受 | >0.95提示冗余 |
| ★★ | HTMT | <0.85（严格）或<0.90（宽松） | 区分效度指标 |
| ★ | 有限总体校正 | $n_{adj} = \frac{n}{1 + \frac{n}{N}}$ | 当n/N>5%时使用 |
| ★ | 抽样间隔 | $K = \frac{N}{n}$ | N总体大小，n样本大小 |
| ★ | 抽样比率 | $f = \frac{n}{N}$ | — |

## 六、高频易错点（考前必看）

| 易错点 | 错误记忆 | 正确记忆 |
|--------|---------|---------|
| 信度与效度关系 | 信度高→效度一定高 | 信度是效度的**必要非充分条件** |
| 定距 vs 定比 | 温度是定比测量 | 温度是**定距**（无绝对零点）；收入才是定比 |
| 标准差分母 | 除以n | 除以 **n-1** |
| 案例研究本质 | 案例研究=定性研究=不科学 | 案例研究是**严谨的实证研究**，可质可量 |
| 焦点小组人数 | 4-5人或20人 | **8-12人**，至少2个组 |
| 相关≠因果 | 相关系数高说明有因果关系 | 相关只衡量**协同变化**，不证明因果 |
| ANOVA vs 多次t检验 | 三组比较用多次t检验 | 三组以上用**ANOVA**，多次t检验增加I类错误 |
| 文献回顾写法 | 按作者罗列研究 | **以概念为中心**组织，避免"电话簿"式罗列 |
